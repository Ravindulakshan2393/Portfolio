## 🚀 How to Deploy to GitHub Pages (2 Minutes)

### Option 1: Direct GitHub Pages Deployment (Easiest)

1. Push all files from this repository to your GitHub repo (e.g. `Portfolio` or `Ravindulakshan2393.github.io`):
   ```bash
   git init
   git add .
   git commit -m "Deploy Portfolio Site"
   git branch -M main
   git remote add origin https://github.com/Ravindulakshan2393/Portfolio.git
   git push -u origin main
   ```

2. On GitHub, go to your repository **Settings** -> **Pages**.
3. Under **Build and deployment**:
   - **Source**: Select `Deploy from a branch`
   - **Branch**: Select `main` and folder `/ (root)`
4. Click **Save**.
5. Your live portfolio will be live at:
   - `https://Ravindulakshan2393.github.io/Portfolio/` (or `https://Ravindulakshan2393.github.io` if named `Ravindulakshan2393.github.io`)

## 💻 Local Preview Instructions

You can run a local HTTP server using Python, Node, or VS Code Live Server:

### Using Python:
```bash
python -m http.server 8000
```
Then open `http://localhost:8000` in your browser.

### Using Node / npx:
```bash
npx http-server .
```
